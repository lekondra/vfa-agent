# ИИ-агент мониторинга стандартов ВФА

Страница-презентация проекта: ИИ-агент ежемесячно проверяет изменения федеральных стандартов внутреннего финансового аудита, сверяет их с Порядком осуществления ВФА и при необходимости готовит проект распоряжения о внесении изменений.

Файлы:
- `index.html` — презентация
- `agent_video.mp4` — ролик «Как создавался ИИ-агент» (57 с)
- `agent_screencast.mp4` — ролик «Как это выглядит в работе» (71 с, иллюстрация)
- `poster.jpg`, `poster2.jpg` — обложки роликов
