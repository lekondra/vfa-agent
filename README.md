# ИИ-агент мониторинга стандартов ВФА

Страница-презентация проекта: ИИ-агент ежемесячно проверяет изменения федеральных стандартов внутреннего финансового аудита и сверяет их с Порядком осуществления ВФА.

Файлы:
- `index.html` — презентация
- `agent_video.mp4` — ролик «Как создавался ИИ-агент» (45 с)
- `poster.jpg` — обложка ролика
